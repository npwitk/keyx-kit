# Fixture catalog

Each fixture is a deck that varies **one thing** from a baseline. Export both to
`.keyx`, run `keyx diff baseline.keyx fixture.keyx`, and the remaining changes
show how that one thing is encoded. Exported fixtures double as the round-trip
test suite.

Status: `auto` = generated by a script in `scripts/`, `manual` = must be built
by hand in Keynote (builds are not exposed to AppleScript as of Keynote 15.4).

## Transitions (auto: `npm run fixtures:transitions`)
- Baseline: `no-transition-effect`
- One deck per effect (44 in Keynote 15.4), two slides, one shape moved and resized
- Variants to add: duration (0.5 / 2.0), delay, automatic vs on-click,
  per-effect options (direction, color for "fade through color")

## Magic Move (manual for the variants)
- Position only / scale only / rotation only / opacity only
- Text morphing: same text box, different words ("match by character" vs "by word")
- Object present on slide 1 only (fades out), slide 2 only (fades in)
- Two identical objects (how does Keynote pair them?)

## Builds (manual)
- Build in: Appear, Dissolve, Move In, Fly In, one "fancy" effect (e.g. Anvil)
- Build out: the same set
- Action builds: Move along path, Rotate, Scale, Opacity
- Text delivery: all at once / by paragraph / by word / by character
- Build order: two objects, both orders; "after previous" vs "with previous" vs on click; delays
- Chart builds: by series, by data point
- Table builds: by row, by column

## Content
- Text: font, size, weight, color, alignment, line spacing, bullets, links
- Shapes: rectangle, rounded rectangle, line with arrowheads, bezier path
- Image: placed, masked, with alpha; image fill
- Movie and audio: in-slide, poster frame, start/end trim, loop
- Chart: bar, line, pie, with data and colors
- Table: header row, merged cells, cell fills, formulas
- Groups and locked objects

## Deck level
- Presenter notes (plain, styled, multiple paragraphs)
- Skipped slide, collapsed/indented slide (outline structure)
- Slide size 16:9 vs 4:3 vs custom
- Theme: Basic White vs Basic Black (how much theme data is embedded?)
- Master slide edit, placeholder use
- Self-playing / loop / kiosk settings
